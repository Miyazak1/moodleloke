## 已实现的学生行为

数学 1.43 的 32 个范围可在题干显示辅助图，另 1 个两点斜率范围仅交卷后显示。其余范围不强塞图。旧的、证据完整的已入库题可直接复核后配图；证据不足或绘图合同不匹配时保留原题。

图接入实际 Agent 自由练习，以及实际 `AgentAdaptiveResultMessage` 交卷题目明细；旧专项解析视图也支持同一图字段。服务端按保存的交卷状态决定阶段。客户端 `phase=review` 等参数不能解锁图；未交卷的报告接口拒绝返回答案和解析。作答后的即时判题仍遵循原有规则，斜率连线继续等到整轮交卷。

外部题优先使用受信审核、版本/内容/字节/阶段绑定的原图。PNG/JPEG 必须真实解码；SVG 采用受限标签并在独立 `img` 上下文呈现。外部公开条件使用单独的事实提取与复核，不伪造原生工件或 Math Lab 准入。签名及内部证据不进入学生 JSON。

可选辅助图无法证明时显示原题；必需图缺失或错版时不发给新练习，并在既有库存事件表记录 `required_figure_unavailable`、题源、题号、版本与原因。原题状态、原图内容与历史学习记录不因此被删除或改写。

## 真正依赖图形的两类试点

新增 `math_reading_pilot` 本地实验题源：分段函数读图求值域、从频数图求加权平均数。题文不重复图中全部数值，必须读取最终图形才能确定条件。

独立求解器从最终 SVG 读取刻度、线段、端点填充、孤立点、柱形尺寸和类别标签，再回算答案；不读取生成器的参数答案。端点开闭、刻度或柱高被改后拒绝；即使改图后答案恰好相同，原图版本绑定也会拒绝。

这是小规模本地试点，没有加入正式插件注册、没有改写冻结 1.43 的范围，默认 `MOODLELIKE_READING_PILOTS_ENABLED=false`。数学 1.43 仍是唯一正式生成插件。试点不是已完成学生难度标定的正式题源，不能用于诊断或独立效果测量。

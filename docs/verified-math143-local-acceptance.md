## 交付行为

- 唯一正式注册插件：verified-math-1.43；冻结引擎版本 1.43.0。
- 三科现有题库、历史作答与原有做题流程保留。物理、化学没有正式出题插件。
- 学生在 Agent 自由练习中选择数学知识点、题量和难度。先读合格库存；不足时由版本化供题任务补题。
- 引擎复核、Oracle、教学准入、宿主题目绑定与历史检查通过后，执行公共候选入库门禁和普通练习发布，再从题库重新读取。
- 旧 Provider 出题、旧插件注册、自动生产调度与后台生产控件停用；原数据保留，移除片段归档于 legacy/question-production。
- 生成资格仅用于普通练习，不用于诊断或独立教学效果测量；不宣称已完成学生难度标定。

## 本地启动

使用 npm run local:setup 安装冻结引擎并应用本地迁移，再运行 npm run local:start。供题任务需要迁移 0101；数学身份唯一约束需要迁移 0100。生产环境示例默认关闭正式插件，不包含本次部署操作。

生产镜像、备份恢复与发布准备的后续验收见 [生产准备记录](math143-production-preparation.md)，操作方案见 [发布与回滚手册](math143-release-runbook.md)。

# CSCALITE × Moodlelike 学习 Agent 合并与旧练习收口计划

> 状态：已决策，待执行
> 日期：2026-09-23
> 目标宿主：`E:\CODE\CSCALITE`
> 成熟实现来源：`E:\CODE\moodlelike`

## 1. 决策摘要

本次合并不把 Moodlelike 作为第二个长期产品部署，也不把 CSCALITE 现有练习代码整体删除。最终形态如下：

1. **学习 Agent 成为学生端唯一的做题与学习入口**，替代原有专项练习、学科练习和独立自适应练习页面。
2. **CSCALITE 继续作为唯一宿主**，负责账号、权限、导航、组织、部署和主数据库。
3. **现有自适应练习底层能力保留并逐步抽成无界面的 `PracticeEngine`**，供 Agent 调用。
4. **自动出题保持独立插件边界**，只生产候选题，不直接控制学生页面，也不进入实时答题关键路径。
5. **学习证据独立保存**。做题会话可以按生命周期清理，但作答、掌握度、错题与训练结果不能跟随聊天删除。
6. Agent 的正式路由为 **`/agent`**，不保留 `/zh/agent` 等语言前缀兼容路由。

这是一项“入口替换 + 能力解耦”工程，不是一次目录复制，也不是一次性删除旧模块。

## 2. 目标产品与技术架构

```text
CSCALITE 应用外壳
├─ 账号、权限、组织、导航、部署
└─ /agent（唯一学生学习入口）
   ├─ Agent 编排与流式 AI
   ├─ 题目级对话（每题独立上下文）
   ├─ 学科问答（独立会话域）
   ├─ 学习计划、薄弱点和复习闭环
   └─ PracticeEngine（无界面）
      ├─ 创建训练轮次与选题
      ├─ 作答、判题、提交与报告
      ├─ 掌握度、补救和验证
      └─ 学习证据写入

QuestionSupplyPlugin（独立插件）
└─ 生成候选题 → 审核/质量门禁 → 正式题库 → PracticeEngine
```

| 边界 | 负责 | 不负责 |
| --- | --- | --- |
| CSCALITE 宿主 | 身份、权限、组织、导航、运行环境、数据库 | 学习交互细节 |
| 学习 Agent | 学习流程、题目交互、AI 辅导、计划与反馈 | 自动生成题目的生产治理 |
| PracticeEngine | 训练轮次、供题、作答、判题、报告、掌握度 | 学生页面与聊天 UI |
| LearningEvidence | 作答事实、错题、能力与掌握度证据 | 临时聊天消息 |
| QuestionSupplyPlugin | 出题、校验、审核、发布候选题 | 直接向学生实时出题、修改学习进度 |

## 3. `csca-special-practice` 的处理原则

`csca-special-practice` 当前同时承载了旧产品页面、练习引擎、AI 辅助和部分管理能力，不能按模块名整体保留或整体删除。

### 3.1 下线的学生端产品能力

- `CscaSpecialPracticePage` 及其独立学生入口。
- 按学科/专题进入的旧专项练习首页、概览和重复导航。
- 与 Agent 重复的独立提示、解析、AI 教练和轮次总结 UI。
- 旧首页中的 mini mock、专项练习推荐卡等重复入口（确认无其他业务依赖后移除）。
- Agent 上线稳定后，旧学生端路由先隐藏和重定向，观察期结束后删除。

### 3.2 必须保留或抽取的底层能力

- `CscaAdaptiveSession`、`CscaAdaptiveRound`、`CscaAdaptiveRoundItem` 等训练事实模型。
- 创建轮次、题目供给、答案检查、轮次提交、报告生成。
- `CscaAdaptiveService` 中的掌握度、补救、验证和训练证据逻辑。
- `AdaptiveQuestionProviderService` 及正式题库读取能力。
- 学习事件、错题、掌握度和报告写入。
- 管理端题库审核、导入和发布能力。

### 3.3 后续拆分的非练习职责

- 组织、权益和管理职责从练习模块中移回各自领域模块。
- 自动出题相关能力只通过插件/契约接入题库，不继续扩张进 `csca-special-practice`。
- 重复 AI 端点在 Agent 功能等价、监控稳定后删除。

## 4. 非目标与禁止事项

- 不把 Moodlelike 仓库整体覆盖到 CSCALITE。
- 不在第一阶段重命名现有数据库表或 Prisma 模型。
- 不把 Moodlelike 的独立登录、站点外壳和部署脚本合入 CSCALITE。
- 不在学生实时答题路径中启用未经审核的在线自动出题。
- 不在新入口验证完成前删除旧路由、控制器和回滚能力。
- 不把题目级聊天、学科问答和学习证据混成同一种会话。
- 不因为清理聊天而删除作答、错题、掌握度或学习报告。

## 5. 选择性回植范围

### 5.1 前端

保留 CSCALITE 的 `App`、认证、全站导航、`SiteHeader`、主题及用户/组织上下文；从 Moodlelike 选择性回植 Agent 页面、组件、API 客户端、样式、流式响应、每题上下文隔离、独立学科问答、工具区、计划、弱点与复习闭环。

路由必须满足：

- `/agent` 是唯一正式地址。
- 全站语言路由器对 `/agent` 做明确例外，不生成 `/zh/agent`。
- 旧入口在灰度期可定向到 Agent，但不增加语言前缀兼容层。

### 5.2 后端

优先回植：会话域、题目级作用域、会话生命周期、DeepSeek 流式输出、异常处理、学习计划、弱点与复习闭环。复用 CSCALITE 的认证、Prisma 和 AI Gateway。

`csca-special-practice`、自适应练习和自动出题区域必须人工选择性合并；它们在 CSCALITE 中仍有活跃开发，禁止整目录覆盖。

### 5.3 数据库

- 使用 CSCALITE 现有主数据库，不搬运 Moodlelike 本地开发数据。
- 应用 `0097_agent_conversation_scopes`、`0098_agent_conversation_lifecycle` 及必要兼容回填。
- 首轮上线不删表、不改主键、不做大规模模型重命名。
- 会话清理只作用于聊天数据；学习证据使用独立保留策略。

## 6. 分阶段执行计划

### 阶段 0：建立可审计的合并基线

任务：

1. 冻结并提交 Moodlelike 当前成熟实现，形成可追溯源版本。
2. 保护 CSCALITE 当前自动出题与专项练习未提交工作，禁止覆盖。
3. 在 CSCALITE 新建专用集成分支或 worktree。
4. 生成 Agent 前端、后端、数据库和配置的文件级差异清单。
5. 记录两个仓库当前构建、测试和迁移基线。

门槛：两个仓库的基线和脏文件归属明确；CSCALITE 可从干净集成基线构建；Moodlelike 目标功能有固定提交号可回溯。

### 阶段 1：先回植后端 Agent 增量

任务：

1. 在备份/演练数据库验证并应用 `0097`、`0098`。
2. 合并会话作用域、生命周期和清理任务。
3. 合并题目级上下文、学科问答独立会话域与访问控制。
4. 合并 DeepSeek 流式响应、中断、超时和降级逻辑。
5. 合并学习计划、弱点和复习闭环所需接口。

验收：后端构建和迁移通过；用户、会话域和题目之间无串线；流式失败可见且不伪装成预设 AI；清理任务不破坏学习证据。

### 阶段 2：建立 `PracticeEngine` 边界

第一步不搬表、不重写算法，只在现有 `CscaAdaptiveService` 外增加 facade/adapter：

```ts
interface PracticeEngine {
  createRound(input: CreateRoundInput): Promise<Round>;
  getRound(roundId: string): Promise<Round>;
  checkAnswer(input: CheckAnswerInput): Promise<AnswerResult>;
  submitRound(roundId: string): Promise<RoundReport>;
  getReport(roundId: string): Promise<RoundReport>;
  getQuestionContext(input: QuestionContextInput): Promise<QuestionContext>;
}
```

让 Agent 依赖该契约而非 legacy 页面模块，并为创建轮次、判题、提交、报告和证据写入补齐契约测试。

验收：旧入口与 Agent 结果一致；重试不会重复提交、计分或写事件；Agent 不依赖旧页面状态。

### 阶段 3：接入成熟 Agent UI

1. 回植 Agent 页面、组件、样式和 API 客户端。
2. 使用 CSCALITE 认证、用户、导航和布局。
3. 落实 `/agent` 无语言前缀路由。
4. 保留旧入口作为灰度回退，不在此阶段删除。
5. 验证桌面、窄屏和触屏下的做题、Agent 流与 Composer。

验收：自由练习、系统推荐、错题复习、学科问答完整；错题可自动打开本题 Agent，答对不强制打断；事件顺序正确；每题只显示本题对话；刷新和重新登录恢复正确状态。

### 阶段 4：内部灰度与双入口验证

使用：

- `AGENT_WEB_ENABLED`
- `VITE_AGENT_WEB_ENABLED`
- `CSCA_AGENT_PRACTICE_WRITE_ENABLED`
- `VITE_AGENT_DISABLED_REDIRECT_URL`
- 宿主契约版本和集成模式配置

自动出题生产开关继续关闭，学生训练只读取已审核题库。仅对白名单开放，保留旧入口，验证数据库、Redis、DeepSeek、并发、多用户隔离和幂等。

退出门槛：无 P0/P1 数据、安全或隔离问题；关键 API 达到线上基线；AI 不可用时仍可做题；关闭开关即可回滚。

### 阶段 5：替换学生端入口

1. 全站“做题、专项练习、学科练习、错题复习”统一进入 `/agent`。
2. 旧页面停止新增功能，只修严重缺陷。
3. 旧路由先做可观测重定向，不立即删除实现。
4. 连续观察至少两个发布周期，且不少于 14 天。

退出门槛：旧入口无有效业务流量；Agent 完成率不低于旧入口；判题/提交无回退；无找不到任务、错题或上下文串线问题。

### 阶段 6：删除重复 UI，完成领域收口

1. 删除旧专项练习和独立自适应练习学生页面。
2. 删除已被 Agent 等价替代且零流量的学生端控制器。
3. 正式拆分 `PracticeEngine`、LearningEvidence、题库管理和组织权益职责。
4. 清理旧路由、重复文案、样式与无调用代码。
5. 表和 Prisma 模型重命名另立迁移，不与入口删除同批实施。

完成标准：学生端只有一个入口和一套状态模型；Agent 只依赖稳定领域接口；自动出题插件可独立关闭、升级或替换。

## 8. 会话与数据生命周期

会话必须分域：

- `QUESTION_ASSISTANCE`：绑定用户、轮次和题目，每题独立。
- `SUBJECT_QA`：独立学科问答，不携带做题上下文。
- 计划、弱点等系统事件使用各自类型，不伪装成用户会话。

生命周期规则：

- 活跃做题会话在本轮及短期复盘期间可恢复。
- 超期聊天先软删除/归档，再批量硬删除。
- 学科问答独立管理，不跟随某道题删除。
- 作答、错题、掌握度、学习事件和报告不属于聊天清理范围。
- 清理任务必须有 dry-run、批次上限、指标和审计记录。

## 9. 自动出题插件契约

1. 插件生成未持久化或候选题。
2. 经过结构、答案、重复度和学科质量门禁。
3. 审核后发布到正式题库。
4. `PracticeEngine` 只消费“已发布、可训练”的题目。
5. 插件停用或升级时，正式题库训练不受影响。

上线初期禁止“学生点击下一题时同步调用模型现生成题目”。

## 10. 测试、指标与发布门禁

必测：登录/刷新/跨设备；自由练习和系统推荐；正确/错误/跳过/暂停/重试；本题问答与切题；学科问答隔离；DeepSeek 流式、超时、限流、断流和无 Key 降级；旧入口与 Agent 判题一致性；聊天清理后的证据完整性；多账号与组织隔离。

每阶段至少执行（以目标仓库实际脚本为准）：

```powershell
npm run build
npm run db:migrate
node scripts/check-cscalite-agent-host-contract.cjs
node scripts/moodlelike-integration-preflight.cjs --self-test
```

迁移必须先备份并在演练环境执行。关键指标包括练习开始/完成/提交成功率、判题一致性、重复写入率、首 token 延迟、流式中断率、模型错误率、上下文串线数（目标 0）、旧路由流量及聊天增长/清理量。

## 11. 回滚方案

1. 关闭 `CSCA_AGENT_PRACTICE_WRITE_ENABLED`，停止 Agent 写训练数据。
2. 关闭 Agent 前后端开关，将用户导回旧入口。
3. 保留向前兼容数据库迁移，不紧急删列或回滚数据。
4. 停止会话清理任务，保留审计日志。
5. 自动出题插件始终可独立关闭。

回滚能力至少保留到阶段 5 的观察期结束。

## 12. 主要风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 两仓库脏改动互相覆盖 | 独立 worktree；按文件/提交选择性回植；禁止整目录复制 |
| 因模块名误删底层引擎 | 先建立 `PracticeEngine` facade，再删除旧页面 |
| 旧入口与 Agent 双状态源 | 灰度期只允许一个入口写入，旧页面仅作受控回退 |
| 会话清理误删学习事实 | 聊天与 LearningEvidence 分域，清理前 dry-run 和外键审计 |
| AI 故障阻断做题 | 非 AI 做题链路独立可用，AI 清晰降级 |
| 自动出题污染正式训练 | 候选题经过质量门禁和发布状态，学生侧不实时生成 |
| 迁移不可逆 | 先备份和演练；初期只做向前兼容扩展 |

## 13. 已确定的产品决策

- Agent 是未来唯一学生学习入口。
- `/agent` 不使用语言前缀，也不为 `/zh/agent` 做兼容。
- 自由练习遵循用户明确选择；系统推荐可以跨科目，但进入前必须说明推荐原因、科目和目标。
- 做题对话按题隔离；学科问答是独立会话产品。
- 自动出题插件化、审核后入库，不与实时学习路径耦合。
- 旧专项练习 UI 最终删除；其自适应训练引擎保留并抽取。
- 合并使用 CSCALITE 主数据库，不迁入 Moodlelike 本地业务数据。

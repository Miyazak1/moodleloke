# CSCAlite 学生端前端设计语言与全站设计规范

版本：2026-09-02  
状态：可作为后续实现基准  
适用范围：CSCAlite 学生端公开页面、练习页面、模考页面、个人学习页，以及与学生体验相关的公共组件

> 本文档用于替代 `rebuild-v1/02-Frontend-Design-Spec.md` 中“橙色留学申请助手”方向下的公开页视觉规范。旧文档保留为历史上下文；新的学生端方向以 CSCA 做题、模考、专项、错题复盘为核心。

## 1. 产品定位

CSCAlite 的学生端首页和公开前端，应该让用户第一眼知道：

- 这是一个面向学生的 CSCA 学习与练习平台。
- 先做一套在线模考，定位当前水平。
- 再根据薄弱知识点进入专项练习。
- 错题会回流到复盘和变式练习。
- 数学、物理、化学不是普通列表，而是有学科特点的互动学习入口。

当前设计语言的核心不是“申请平台”，而是“清楚、舒服、有科学感的做题工具”。

留学中国、院校、奖学金、咨询等内容可以保留，但在视觉和信息层级上应作为辅助内容。首页和学生主路径必须围绕 CSCA 练习闭环展开。

学生端不要展示老师端、出题端、审核端、发布端或管理工作台概念。相关能力即使存在，也不应该出现在学生首页和学生学习路径里。

## 2. 参考网站如何转化为 CSCAlite 规范

CSCAlite 不应复制任何单一网站，而是吸收它们各自适合学习产品的部分。

| 参考 | 地址 | 借鉴点 | 不借鉴 |
| --- | --- | --- | --- |
| Linear | https://linear.app/ | 产品界面成为主视觉；工作流层级清楚；文字克制；工具感强。 | 不做成 B2B 工程团队软件。 |
| Vercel | https://vercel.com/ | 状态清晰；能力分组明确；导航和 CTA 干净；系统可信感强。 | 不使用大面积黑色，也不做开发者基础设施气质。 |
| Superlist | https://www.superlist.com/ | 轻松、舒服、现代；任务流清楚；下一步动作明确。 | 不变成普通待办工具。 |
| Khan Academy | https://www.khanacademy.org/ | 教育可信感；低压力；结构清楚；学习目标明确。 | 不做得过于朴素或机构化。 |
| Brilliant | https://brilliant.org/ | 互动学习、可视化 STEM、即时反馈、边做边学。 | 不过度游戏化，也不遮住真实题目。 |
| Typeform / Tally | https://www.typeform.com/ / https://tally.so/ | 单题聚焦、表单舒适、答题压力低。 | 不把模考做成随意问卷。 |

综合方向：

> Superlist 的舒适感 + Linear 的克制工具感 + Khan Academy 的教育可信感 + Brilliant 的互动学习感 + Vercel 的状态清晰度。

## 3. 体验原则

### 3.1 学生第一

每个学生端页面都应该回答至少一个问题：

- 我现在应该先做什么？
- 我适合练哪个科目或知识点？
- 我刚才错在哪里？
- 我下一步该去哪？
- 我在哪里找模拟卷或真题？

回答不了这些问题的内容，应降级为辅助信息、放入 footer，或从学生主路径中移除。

### 3.2 写产品文案，不写设计说明

页面上的文案只能面向学生，不要把内部设计讨论写到页面上。

禁止这类文案：

- “这个布局更有呼吸感。”
- “这版体现年轻和极客感。”
- “卡片错落让页面不呆板。”
- “页面外层负责动感。”

改成这类文案：

- “先做一套模考，快速定位当前水平。”
- “错题会进入下一组变式练习。”
- “数学看图像，物理看运动，化学看结构。”
- “交卷后查看分数、薄弱知识点和下一步专项。”

### 3.3 先展示可用产品，再讲理念

首页首屏不能只有口号。成熟产品首页应该在第一屏就展示真实或接近真实的产品界面。

推荐首屏结构：

- 左侧：一句清楚的产品定位、主 CTA、简短学习闭环。
- 右侧：科目互动实验台或答题产品界面。
- 下方：模考、专项、科目、错题复盘入口。

### 3.4 做题时安静，做题外有趣

实际答题区必须安静、稳定、少干扰：

- 计时清楚。
- 题干清楚。
- 选项状态清楚。
- 当前题号和进度清楚。
- 解析出现位置固定。
- 下一步动作明确。

极客感、学科动效和视觉趣味应放在科目入口、报告、路径、滚动转场和 footer 衔接中。不要让动效干扰正在阅读的题目。

## 4. 视觉语言

当前方向命名：**Calm Science Lab / 清爽科学练习台**。

关键词：

- 清楚
- 舒服
- 学生友好
- 轻科学感
- 有学科互动
- 工具感克制
- 不焦虑

### 4.1 色彩体系

从当前首页 demo 沉淀出的核心 token：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f6fbf6` | 页面主背景。 |
| `--bg-2` | `#eef8f7` | 辅助背景、浅渐变。 |
| `--paper` | `#ffffff` | 卡片、答题面板、信息面板。 |
| `--ink` | `#202337` | 主文字。 |
| `--muted` | `#5e6b7d` | 正文和说明。 |
| `--faint` | `#8a96a8` | 元信息、footer note。 |
| `--line` | `#dbe8df` | 柔和边线。 |
| `--line-strong` | `#bfd6cc` | 强一点的分割线。 |
| `--blue` | `#315dff` | 主按钮、当前状态、数学重点。 |
| `--blue-soft` | `#e9efff` | 蓝色浅底。 |
| `--mint` | `#13c7a3` | 进度、正确、物理重点。 |
| `--mint-dark` | `#087c66` | mint 浅底上的文字。 |
| `--mint-soft` | `#dcfbf2` | 进度浅底。 |
| `--lime` | `#b7ef43` | 高亮、免费、积极提示。 |
| `--lime-soft` | `#f0ffd3` | lime 浅底。 |
| `--coral` | `#ff715e` | 薄弱点、警示、化学重点。 |
| `--coral-soft` | `#ffe9e4` | 薄弱点浅底。 |
| `--amber` | `#f1a826` | 化学辅助强调。 |

使用规则：

- 蓝色是主要行动色，用于“开始模考”“继续练习”“提交答案”。
- Mint 表示进度、正确、准备度、稳定推进。
- Lime 表示轻高亮和免费，不要大面积铺满。
- Coral 表示薄弱点、热力、警示、化学重点。
- Footer 继续使用同一套浅色科学场域，不要突然变成绿色块、黑色块或旧橙色 footer。
- 页面不要被单一颜色支配，避免全蓝、全绿、全橙、全米色。

### 4.2 背景

推荐使用：

- 浅色科学网格。
- 轻微渐变背景。
- 低透明度斜向色带。
- SVG 曲线、轨迹、波形、坐标、轨道、路径线。
- footer 与上一段用柔和曲线和渐变融为一个区域。

避免使用：

- 大面积黑色。
- 大面积纯绿色 footer。
- 装饰性渐变圆球或无意义光斑。
- 和学科、做题、路径无关的抽象图。

### 4.3 字体与字号

推荐字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
"Segoe UI", "Microsoft YaHei", sans-serif
```

规则：

- `letter-spacing` 保持 `0`。
- 不使用负字距。
- 中文标题要有力量，但不能大到压迫或重叠。
- 长文案应自然换行，不遮挡后续内容。
- 标题可使用 `text-wrap: balance`。
- 正文可使用 `text-wrap: pretty`。

推荐字号：

| 用途 | 桌面 | 移动端 |
| --- | --- | --- |
| 首页 H1 | `clamp(38px, 4.35vw, 66px)` | `clamp(32px, 9.6vw, 44px)` |
| Section H2 | `clamp(29px, 2.85vw, 46px)` | `clamp(26px, 7.6vw, 36px)` |
| 重点卡片 H2 | `clamp(25px, 2.15vw, 36px)` | `28px-34px` |
| 卡片 H3 | `19px-22px` | `18px-20px` |
| 正文 | `15px-16px / 1.7-1.9` | `15px-16px / 1.65-1.8` |
| 元信息 | `12px-13px` | `12px-13px` |

## 5. 布局规范

### 5.1 宽度

首页和公共产品介绍页：

```css
width: min(1580px, calc(100% - 56px));
```

做题、模考、专项等工作台页面：

```css
width: min(1320px, calc(100% - 48px));
```

长阅读内容：

```css
max-width: 920px;
```

### 5.2 间距

推荐节奏：

- Hero 桌面上下留白：`80px-120px`。
- 主 section 上下留白：`96px-120px`。
- Section header 到内容：`40px-56px`。
- 卡片网格间距：`14px-28px`。
- Footer CTA 到 footer：通过曲线和渐变衔接，不使用硬分割线。

### 5.3 构图

允许有控制的非对称：

- 首页首屏可以左右不等宽，产品界面可以比文字区更大。
- 入口卡片可以有一个主卡 + 多个次卡。
- 科目区可以错落，但色块要是“学科标识”，不能压过内容。
- 学习路径可以轻微错位，但不能造成阅读负担或重叠。

不要把页面做成一组上下堆叠的大卡片。页面 section 应该是完整的横向区域或开放式布局；卡片只用于功能入口、工具面板、重复内容、弹窗和状态模块。

## 6. 核心组件规范

### 6.1 Header

学生端公开导航使用真实项目导航：

- 首页
- 留学中国
- CSCA 准备
- 科目学习
- 专项，badge：免费
- 在线模考，badge：新
- 模拟卷，badge：新
- 真题，badge：免费
- 咨询

规则：

- 主 CTA 使用“开始模考”或“开始免费模考”。
- 登录和语言切换是工具动作，不抢主 CTA。
- 小屏下导航可以横向滚动或分组，但不能挤成多行乱码。
- 留学中国保留，但首页视觉重点应给 CSCA 练习路径。

### 6.2 Button

Primary：

- 蓝底白字。
- 用于开始模考、继续练习、提交答案。

Secondary：

- 白底或半透明底。
- 深色文字。
- 用于查看路径、探索科目、查看详情。

Highlight：

- Lime 底。
- 只用于少量免费、选择入口或积极提示。

按钮规则：

- 常规按钮最小高度 `42px`。
- 工作台内部控制可为 `36px-40px`。
- 圆角默认 `8px`，只有标签和 segmented controls 使用 pill。
- 有明确动作的按钮可以配 icon。
- Hover 轻微上浮 `1px-2px`，不要夸张弹跳。

### 6.3 Cards / Surfaces

通用表面：

- 背景：白色或半透明白。
- 边框：`1px solid var(--line)`。
- 圆角：`8px-18px`。
- 阴影：轻，少用，不要堆叠重阴影。

卡片类型：

- 入口卡：解释一个功能入口，并有一个明确动作。
- 答题面板：稳定的工作区域。
- 反馈卡：报告、雷达图、热力图、错题路径。
- 科目 lane：开放式横向区域 + 小型学科标识。
- Footer link group：安静的链接组，不做成促销卡。

### 6.4 Tags / Badges

适合标签化的内容：

- 免费
- 新
- CSCA Style
- 即时解析
- 当前题
- 薄弱点
- 已完成

规则：

- 小而清楚，不装饰化。
- 一行不要堆太多标签。
- 导航 badge 不能破坏文字对齐。

### 6.5 做题组件

模考和专项练习页面必须有：

- 计时器。
- 题号。
- 进度图。
- 科目/知识点标签。
- 选项。
- 解析。
- 下一题/提交。
- 报告入口。
- 错题回流提示。

选项状态：

- 默认。
- Hover。
- 已选择。
- 正确。
- 错误。
- Disabled。

状态变化不能造成布局跳动。解析出现位置要固定，不要把学生正在看的题目顶走。

## 7. 动效规范

动效目标：让页面有生命力，但不制造干扰。

适合使用动效的地方：

- 首屏科目实验台。
- 下拉时 section reveal。
- 入口卡片 stagger 出现。
- 进度格逐个点亮。
- 雷达图/热力图/错题路径出现。
- 学科 visual 切换。
- Footer 曲线和漂浮元素。

不适合使用动效的地方：

- 正在阅读的题干。
- 大段正文。
- 答案选项本身的持续循环。
- 会影响点击准确性的元素。

推荐时间：

- Hover：`160ms-220ms`。
- Section reveal：`620ms-760ms`。
- Stagger：`40ms-140ms`。
- 线条绘制：`900ms-1200ms`。
- 氛围循环：`3s-9s`，低透明度，远离主要阅读区。

必须支持：

```css
@media (prefers-reduced-motion: reduce) { ... }
```

## 8. 全站页面设计

### 8.1 首页

目标：

让学生在 5 秒内知道 CSCAlite 是什么，并愿意开始第一套模考。

推荐模块顺序：

1. Header：真实导航 + 开始模考。
2. Hero：CSCA 模考、薄弱点、专项练习的核心表达。
3. 首屏产品预览：科目互动实验台或答题界面。
4. 入口卡：在线模考、专项、科目学习、错题复盘。
5. 答题流程预览：做题中、交卷报告、错题复盘。
6. 科目学习：数学、物理、化学。
7. 学习路径：模考定位、错因诊断、专项复盘、回到模拟卷。
8. Footer CTA：引导开始模考。
9. Footer：完整但安静的站点链接。

推荐核心文案：

- “先做一套 CSCA 模考。”
- “看清薄弱点。”
- “再进入专项练习。”
- “错题回流到变式题。”

### 8.2 CSCA 准备页

目标：

解释 CSCA 备考逻辑，并把学生引向练习。

内容结构：

1. CSCA 准备是什么。
2. 需要关注哪些科目。
3. 什么时候适合开始模考。
4. 如何用模考结果进入专项练习。
5. 模拟卷、真题和错题复盘入口。

视觉：

- 比首页更安静。
- 使用流程、时间线、科目卡。
- 不要让学校申请内容压过 CSCA 练习内容。

### 8.3 科目学习页

目标：

让学生进入数学、物理、化学，并理解每个学科的练习方式。

学科视觉：

- 数学：函数曲线、坐标、几何关系、概率网格。
- 物理：力箭头、波形、运动轨迹、电路。
- 化学：分子结构、化学键、反应路径、pH/溶液。

每个科目页应包含：

1. 科目定位。
2. 重点知识点。
3. 免费入门专题。
4. 可视化概念工具。
5. 进入练习 CTA。
6. 最近进度或下一题组。

### 8.4 专项练习页

目标：

让日常刷题变成短、清楚、可持续的练习队列。

必须包含：

- 科目筛选。
- 知识点筛选。
- 难度或准备度标签。
- 题量。
- 免费专题入口。
- 继续练习。
- 和模考报告/错题复盘的关系。

视觉：

- 比首页密度更高。
- 入口清楚，少装饰。
- 可视化专题可以丰富，但题目列表要稳定。

### 8.5 在线模考页

目标：

模拟真实答题节奏，并让学生交卷后知道下一步。

页面状态：

- 模考列表。
- 开始前说明。
- 答题中。
- 交卷确认。
- 报告页。

答题中：

- 背景安静。
- 计时清楚。
- 进度清楚。
- 选项稳定。
- 尽量减少动画。

报告页：

- 总分。
- 科目维度。
- 知识点热力。
- 错题列表。
- 下一组专项推荐。

### 8.6 模拟卷页

目标：

帮助学生选择适合当前阶段的模拟卷。

卡片或列表字段：

- 模拟卷标题。
- 科目覆盖。
- 题量。
- 预计用时。
- 最近一次状态。
- 开始、继续或复盘。

视觉：

- 借鉴 Vercel 的状态清晰度。
- 借鉴 Linear 的列表精确感。
- 筛选只在能降低选择成本时出现。

### 8.7 真题页

目标：

让免费真题容易筛选、查看和下载。

设计：

- 文档库气质。
- 年份、科目、类型筛选。
- 免费标识清楚。
- 查看和下载动作清楚。
- 不要用过多动效。

### 8.8 留学中国

目标：

作为学生做 CSCA 准备时的背景信息，而不是首页主叙事。

设计：

- 视觉能量低于 CSCA 练习页面。
- 使用搜索、筛选、院校卡、对比面板。
- 在适当位置引导回 CSCA 准备或模考。

首页策略：

- 可以保留在 nav。
- 首页正文少讲，footer 中保留完整入口。
- 不要让学校申请内容占据首屏。

### 8.9 咨询页

目标：

提供可选帮助，不制造焦虑。

设计：

- 可信、克制。
- 解释咨询能解决什么问题。
- 不用促销式强刺激。
- 保留自助练习入口。

### 8.10 账号 / 学习看板

目标：

让学生回到自己的学习状态。

必备模块：

- 最近模考成绩。
- 当前薄弱知识点。
- 错题队列。
- 继续练习 CTA。
- 收藏或保存的模拟卷/真题。
- 订单或服务状态。

视觉：

- 像个人学习 dashboard。
- 使用状态卡、时间线、列表，不使用营销卡片。

### 8.11 后台 / 内部页面

后台不属于学生端公开设计叙事，但可以共享基础 token 和组件。

规则：

- 更高密度。
- 更少装饰。
- 表格、筛选、表单、状态优先。
- 不把后台概念暴露到学生首页和学生学习路径。

## 9. 响应式规范

断点：

- Mobile：`< 760px`
- Tablet：`760px-1180px`
- Desktop：`>= 1180px`
- Wide desktop：`>= 1440px`

规则：

- 任意断点不能文字重叠。
- 移动端 H1 不超过 `44px`。
- 首屏产品预览在移动端放到文案下方。
- 装饰性漂浮卡片在碰到正文前隐藏。
- 导航可横向滚动，但主 CTA 要保持可见。
- 答题选项移动端单列。
- Footer tablet 两列，mobile 一列。

必须检查的视口：

- `390x844`
- `768x1024`
- `1024x768`
- `1440x900`
- `1920x1080`

## 10. 可访问性

最低要求：

- 可点击区域尽量不小于 `44px`。
- 有清楚 focus 状态。
- 正文对比度满足可读性。
- 正确、错误、警示不能只靠颜色表达。
- 切换类按钮要有明确 active 状态。
- 装饰 SVG 使用 `aria-hidden`。
- 有信息含义的图表需要文字摘要。

## 11. 代码落地建议

当前 CSS 架构已经形成较好的分层：

- `base.css`：token、reset、基础排版。
- `shared-components.css`：共享 UI primitives。
- `layout.css`：通用布局。
- `brand.css`：公共品牌 chrome。
- `public-shell.css`：公共页面 shell。
- Feature CSS：各页面自己的样式。

建议迁移顺序：

1. 将本文档的学生端 token 落到 `base.css` 或新的 token 区块。
2. 更新 `brand.css` 中 header/footer，使其匹配“清爽科学练习台”。
3. 将当前 `csca-home-demo.html` 的方向迁移到 `HomePage.tsx` 与 `home.css`。
4. 依次改造：
   - `mock-exam.css`
   - `special-practice.css`
   - 科目 visualizer 样式
   - `past-papers.css`
5. 留学中国相关页面保持可用，但视觉降级为辅助内容。
6. 后台继续保持高密度工具风格，不跟首页一起强行炫技。

不要用一个全局覆盖文件一次性改完整站。应按页面族逐步迁移，并保持 CSS ownership 清楚。

## 12. 验收清单

首页：

- 学生 5 秒内能知道这是 CSCA 学习/练习平台。
- 主 CTA 明确指向开始模考。
- 在线模考、专项、科目学习、错题复盘都能看见。
- 不出现老师端、出题端、审核端、管理端语言。
- 不出现解释设计意图的文案。
- 目标视口无文字重叠。
- Footer 和上方区域视觉上属于同一套系统。

练习页面：

- 计时、进度、选项、解析、提交、下一步都清楚。
- 报告能直接连接专项练习和错题复盘。
- 动效不干扰题干阅读。

全站：

- 导航标签与真实路由一致。
- 留学中国是辅助，不抢 CSCA 练习主线。
- 卡片、按钮、标签、状态面板共享同一 token 系统。
- 移动端不是压缩后的桌面端。
- 公开页面看起来像一个产品，而不是多个模板拼接。

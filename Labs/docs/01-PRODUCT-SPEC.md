# CSCAPilot Learning Agent 产品规格

> 状态：Draft v0.2
>
> 更新时间：2026-09-17
>
> 依赖文档：[总体架构](../ARCHITECTURE.md)

## 1. 产品目标

CSCAPilot Learning Agent 将现有的学习档案、自适应练习、错题复习、模考、真题和 AI 辅导能力组织成一个自然语言入口。

Web Agent Pilot（`WA-P1`）的成功标准不是“能够聊天”，而是用户用一句话表达学习目标后，Agent 能可靠地创建或打开一个真实的学习任务，并让用户继续完成该任务。

产品长期北极星是帮助学生在目标考试日期前，建立达到其 CSCA 理想分数所需且可验证的能力。系统持续判断能力差距、安排下一步并用独立作答重新校准；它不承诺具体成绩，也不把练习数量、活跃度或模型生成的内部分数当作最终结果。

核心价值：

- 减少用户在多个页面之间寻找功能的成本；
- 根据学习状态推荐下一步，而不是只展示静态入口；
- 把解释、计划和建议连接到可执行的练习、复习、模考或资料；
- 让同一套能力以后可以通过网页和外部 Agent 插件使用。

### 1.1 平台定位与长期演进

CSCAPilot 当前首先是做题训练产品，不以首个阶段复制完整 LMS 为目标。平台从可信题源、真实作答、分级辅助和学习证据切入，再把教学动画、引导演示、例题、视频与独立验证接入同一学习闭环；教师、课程、班级和机构能力在训练与教学闭环稳定后逐步建设。

长期目标是覆盖 Moodle 所承载的核心教学场景，但系统仍以学生目标、学习证据和下一步决策为运行时中心，课程是内容组织与教师发布方式，不成为另一套学习事实源。当前开发必须保留统一活动、版本化内容、组织与权限、正式证据和能力接口边界，同时明确延后完整课程编辑器、复杂成绩册、通用协作套件、插件市场和全量 LMS 迁移。

完整架构决策见 [83-AI-NATIVE-TRAINING-TO-LEARNING-PLATFORM-ADR.md](./83-AI-NATIVE-TRAINING-TO-LEARNING-PLATFORM-ADR.md)。

## 2. Web Agent Pilot 用户

### 2.1 主要用户

正在准备 CSCA 数学、物理或化学考试的注册学生，已经完成基础学习档案，可能拥有练习记录、错题或模考记录。

### 2.2 次要用户

- 新注册、尚无训练数据的学生；
- AI 额度不足但仍可使用标准练习和资料的学生；
- 通过 Codex 等外部 Agent 连接 CSCAPilot 的现有用户。

### 2.3 WA-P1 暂不服务

- 教师批量布置任务；
- 组织管理员管理成员和额度；
- 未登录用户的长期 Agent 会话；
- 通用学术问答或与 CSCA 无关的开放式聊天。

## 3. 用户任务

### 3.1 P0：首发必须支持

| 用户表达 | Agent 应完成的结果 |
| --- | --- |
| “我今天应该学什么？” | 读取学习看板并给出一个可执行的首选任务 |
| “给我做一组化学薄弱项练习” | 创建 5 题自适应练习并返回入口 |
| “测一下我的物理水平” | 创建 20 题诊断并返回入口 |
| “复习我到期的错题” | 读取复习队列并创建或打开复习任务 |
| “继续上次的模考” | 找到未提交模考并返回继续入口 |
| “找 2026 年化学真题” | 返回匹配的真题或资料套装 |
| “这道题给我一点提示” | 在明确题目上下文中调用 AI 提示 |
| “解释一下刚才为什么错了” | 在明确题目和作答上下文中生成解析 |
| “分析我上传的这份试卷/题目截图” | 安全处理文档或图片，识别内容并提供带页码/区域引用的分析 |
| “我的 AI 额度还有多少？” | 返回实时额度和适用范围 |
| “我的化学目标是 80 分” | 按有效评分规则确认并版本化保存目标，重新生成方案 |
| “我离目标还差什么？” | 返回有证据和置信度的关键能力差距；证据不足时推荐诊断 |

### 3.2 P1：WA-P1 稳定后支持

- 生成本周学习总结；
- 修改学习计划和考试月份；
- 按薄弱知识点生成组合复习任务；
- 在不同对话中继续最近生成的 Artifact；
- 根据用户偏好在“提示优先”和“直接解析”之间切换。

### 3.3 后续能力

- 主动提醒与后台任务；
- 教师/组织工作流；
- 多周计划自动调整；
- 经正式统计校准的达标概率与长期学习轨迹；
- 学习时间变化的计划模拟；
- 将用户附件保存为长期个人知识库；
- 语音输入与实时语音辅导；
- 跨平台完整会话同步。

## 4. 产品边界

### 4.1 Agent 可以做

- 查询当前用户有权限访问的学习数据；
- 创建低风险、可撤销的练习或诊断任务；
- 打开或继续已有学习对象；
- 调用 CSCAPilot AI 服务生成提示、解析和总结；
- 在确认后修改学习档案或提交不可撤销任务；
- 清楚说明使用了哪些数据和消耗了多少额度。
- 接收私有文档和图片附件，识别内容并基于附件进行有引用的分析。

### 4.2 Agent 不可以做

- 猜测用户成绩、掌握度或剩余额度；
- 在缺少题目上下文时虚构“刚才那道题”；
- 绕过付费、登录、资料可见性或组织权限；
- 未确认就提交模考或进行高影响修改；
- 把生成式回答冒充官方标准答案；
- 把用户上传附件自动发布为公开资料或题库；
- 将网页中的内部管理接口暴露给学生或外部插件。

## 5. WA-P1 信息架构

### 5.1 左侧导航

- 下一步：系统推荐、自由练习入口与当前学习恢复；
- 学习计划：目标、阶段安排和当前计划版本；
- 学习历程：按日期和阶段聚合的真实学习事件；
- 错题与薄弱点：来自正式作答和复习队列的证据视图；
- 学习资料：真题、已审核教学资产和后续视频；
- 学习设置：默认学习方式、目标与学习偏好；
- 底部用户入口：只进入个人设置和主站。

左栏不提供“新建聊天”和重复会话列表。底层 conversation 仅承担恢复、审计和上下文隔离，学生面对的是一条连续学习旅程。完整决策见 [80-AGENT-LEARNING-JOURNEY-AND-CONVERSATIONAL-TEACHING-ADR.md](./80-AGENT-LEARNING-JOURNEY-AND-CONVERSATIONAL-TEACHING-ADR.md)。

### 5.2 常驻聊天区

- 当前学习旅程和 Agent 回复，任何学习任务打开后仍保持可见与可输入；
- 任务理解或简短计划；
- 工具执行状态；
- Artifact 结果卡片；
- 确认、取消、重试和反馈；
- 固定在底部的输入框，最新消息保持在其上方；
- 自动绑定当前任务、题目、知识点、作答阶段和已发生辅助；
- 做题期间进入安静陪伴状态，只在自然边界或学生主动求助时发言。

### 5.3 类型化任务区

- 逐题练习、真题与正式提交；
- 知识点动画、讲解与未来的视频；
- 手写过程分析、阶段验证和学习报告；
- 学习设置与其他会改变决策的类型化工具。

任务区应可收起、可调整宽度，并可与聊天区交换左右/主次位置；交换只改变布局，不改变语义。聊天区始终存在，任务区只切换当前执行工具。移动端任务区可覆盖显示，但关闭后必须恢复同一聊天、Composer 和任务上下文。

## 6. 核心用户流程

### 6.1 今日学习建议

```text
用户进入 Agent（也可以主动询问）
  -> Agent 读取目标、学习证据、进行中任务与可用题源
  -> 识别最高优先级建议
  -> 说明推荐原因
  -> 展示任务卡
  -> 用户开始练习/复习/模考
```

规则：

- 优先使用看板已有的推荐和学习状态；
- 如果没有历史数据，推荐诊断或基础练习；
- 不为了显得个性化而编造薄弱点；
- 主推荐只保留一个，最多提供两个备选操作。

学生不需要每次发送“我今天应该学什么”。已有目标和状态足以形成下一步时，Agent 首页应直接展示可执行建议；自然语言用于追问、调整或表达例外意图。

#### 6.1.1 做题中的 Agent 联动

```text
任务面板聚焦当前题
  -> Composer 自动绑定经过校验的题目上下文
  -> 学生直接作答，聊天保持安静
  -> 学生通过快捷按钮或自然语言求助
  -> 简短反馈进入聊天；高亮、手写详情或教学资产由任务面板执行
  -> 辅助曝光进入证据链，但不得被计为独立完成
```

学生说“这题”“刚才为什么错”或“检查我的过程”时，Agent 应先使用活动上下文，不得让学生重复说明系统已经知道的试卷、题号或知识点。

#### 6.1.2 稳定误区与教学干预

同一知识点形成重复错误、多次提示后仍失败或教学后验证失败时，Agent 可以在当前题提交或 mini-set 完成后向聊天插入非阻塞教学卡。学生可选择“现在学习”“稍后提醒”或“暂时跳过”。接受后，动画、微课或视频在任务面板打开，原题与进度保持；完成教学后必须通过独立题产生新证据。

#### 6.1.3 任务完成与再次进入

任务完成后，聊天只给出基于真实结果的聚合总结、证据限制和一个首选下一步，同时允许继续、换知识点或结束。再次进入时优先恢复未完成 Round、教学或验证，并明确说明恢复了什么；不得要求学生从多个聊天中寻找上次进度。

### 6.2 创建自适应练习

```text
用户说明科目/目标
  -> 补齐缺失的必要参数
  -> 创建 practice session
  -> 创建 5 题 round
  -> 返回 practice_session Artifact
  -> Agent 内打开类型化练习工作区完成
  -> Agent 内展示报告并依据新证据安排下一步
```

必要参数：科目。语言可从账号设置或当前会话推断，模式默认为 `practice`。

若用户指定不存在或无法匹配的知识点，Agent 应给出可选知识点或退回科目级练习，不能静默选择无关内容。

### 6.3 创建诊断

与自适应练习类似，但模式为 `diagnostic`，题量为现有系统定义的 20 题。创建前应明确诊断比普通练习更长。

### 6.4 错题复习

```text
读取 review queue
  -> 按科目、到期状态和优先级筛选
  -> 有结果：返回复习内容与入口
  -> 无结果：说明当前没有到期项目，并推荐普通练习
```

`WA-P1` 不由 Agent 直接将复习项标记为完成。完成状态继续由真实复习流程写入。

### 6.5 继续模考

```text
读取 my attempts
  -> 查找未提交且最近更新的 attempt
  -> 有一个：直接返回继续入口
  -> 有多个：展示最多三个让用户选择
  -> 没有：推荐可开始的公开试卷
```

提交模考属于不可轻易撤销操作，必须明确确认。

### 6.6 搜索真题

```text
解析科目、年份、类别、语言
  -> 搜索公开 past papers 和 resource bundles
  -> 返回相关性最高的结果
  -> 用户打开详情或受控下载入口
```

Agent 只返回已发布且当前用户可访问的公共资料。`WA-P1` 支持把文件作为私有对话附件分析，但附件不会自动成为公开真题或题库内容。

### 6.7 AI 提示与解析

```text
确认 roundId/questionId
  -> 检查额度和权益
  -> 调用 hint 或 explanation
  -> 展示 AI 生成标识和额度变化
  -> 收集反馈
```

如果缺少明确题目上下文，Agent 必须先询问题目或引导用户进入练习，不得猜测。

提示与解析只是底层能力，不是最终产品形态。练习页、Agent、附件分析和未来插件统一使用分级学习辅助：题意澄清、概念提醒、下一步提示、检查当前步骤、换一种讲法、相关例题、完整解析和前置知识补习。系统根据作答阶段与既有曝光决定当前允许的最高层级；已看提示、示例或答案必须记录并影响本题证据独立性。主动求助与系统教学干预共用教学资产和效果验证，详细决策见 [55-LEARNING-ASSISTANCE-AND-TEACHING-ASSET-ADR.md](./55-LEARNING-ASSISTANCE-AND-TEACHING-ASSET-ADR.md)。

## 7. 对话与交互规则

### 7.1 回答结构

任务型回答优先采用：

1. 一句话说明已理解的目标；
2. 必要时说明选择依据；
3. 展示可操作的 Artifact；
4. 给出一个明确主操作；
5. 补充额度、限制或数据来源。

普通结果不展示冗长的内部推理或完整工具参数。

### 7.2 澄清规则

只有缺少执行所需的关键参数时才追问。例如创建练习缺少科目时需要询问；语言、题量等有安全默认值时不应逐项盘问。

一次最多询问两个紧密相关的问题，并优先提供可点击选项。

### 7.3 确认规则

| 操作 | 行为 |
| --- | --- |
| 读取学习数据 | 直接执行 |
| 创建练习、诊断或复习任务 | 直接执行并告知 |
| 调用低成本 AI 提示 | 显示扣费结果；价格策略要求时先预估 |
| 修改学习计划或档案 | 展示字段变更摘要后确认 |
| 提交模考 | 必须明确确认 |

### 7.4 语言规则

- 默认跟随用户当前界面或账号的题目语言设置；
- 用户明确使用另一种语言时，当前对话可以跟随用户；
- 题目原文与解释语言可以不同，但必须清楚标注；
- `WA-P1` 重点保证中文和英文。

## 8. 页面与系统状态

### 8.1 首次使用

显示四个真实可执行建议：开始诊断、开始科目练习、复习错题、搜索真题。没有数据时不得展示虚假的掌握度或错题数量。

### 8.2 加载中

区分“Agent 正在回复”和“正在创建练习/查询资料”等工具执行状态。超过正常等待时间后允许取消。

### 8.3 空结果

说明查询条件和空结果含义，并提供最接近的下一步。例如没有到期错题时推荐科目练习，而不是显示错误。

### 8.4 权限或登录不足

保留当前任务意图，在用户登录或授权成功后允许继续。不得只把用户送回首页。

### 8.5 AI 额度不足

明确说明只有 AI 辅导暂停；标准题目、答案、学习记录和真题仍然可用。提供管理额度和继续无 AI 练习两个入口。

### 8.6 工具失败

- 安全的读取操作可以自动重试一次；
- 写操作失败不得假定成功；
- 如果服务状态不明确，应查询幂等结果再决定是否重试；
- 给用户可执行的重试或替代路径。

### 8.7 断线恢复

重新进入对话后恢复已完成消息、运行状态和 Artifact。仍在执行的任务显示最新状态；无法恢复时明确标记失败，不重复扣费或创建任务。

## 9. Artifact 展示要求

所有 Artifact 卡至少显示：

- 类型和标题；
- 科目、题量、状态等关键元数据；
- 为什么推荐或如何产生；
- 一个主要操作；
- 必要的次要操作；
- 数据更新时间或生成时间；
- 若使用 AI，显示额度变化。

主要 Artifact：

| 类型 | 主操作 |
| --- | --- |
| `practice_session` | 开始/继续练习 |
| `review_session` | 开始复习 |
| `mock_exam` | 开始/继续模考或查看报告 |
| `past_paper_bundle` | 查看资料 |
| `readiness_report` | 查看薄弱项 |
| `weekly_report` | 查看学习总结 |
| `study_plan` | 查看/确认计划 |

## 10. 额度与付费体验

- 输入框附近显示当前可用额度，但不制造持续焦虑；
- 只有调用 CSCAPilot 托管 AI 时扣除 CSCAPilot AI 额度；
- 每次扣费后显示本次消耗和剩余额度；
- 同一幂等请求不得重复扣费；
- 生成失败且没有有效结果时应按现有计费政策退款或不扣费；
- 白名单、组织权益和个人额度统一由现有 entitlement 服务判定。

## 11. 数据与隐私体验

- Agent 使用学习记录时说明数据类别，例如“根据最近练习和错题”；
- 不在回复中暴露不必要的账号、组织或内部标识；
- 用户可以删除网页 Agent 对话；
- 删除对话不等于删除真实练习或模考记录，需要在界面中说明；
- 外部插件默认不同步完整对话，只保存必要的业务结果和审计记录。

## 12. WA-P1 验收标准

### 12.1 功能验收

- P0 十二类任务均可从自然语言到达真实结果；
- Agent 不返回不存在的练习、模考、资料或额度；
- 所有创建型工具具备幂等保护；
- 模考提交和档案修改遵守确认规则；
- AI 生成调用准确返回额度变化；
- 断线刷新后能恢复已完成的对话与 Artifact；
- 中文和英文核心流程可用；
- 桌面与移动端均无关键操作遮挡或横向溢出。
- 首次进入 Agent 不发送消息也能获得一个有依据的可执行下一步；
- 当前题求助无需重复提供题号，聊天反馈与任务区操作保持同一上下文；
- 做题期间普通选择、计时和导航不产生聊天噪声；
- 动态消息、教学卡和长会话恢复后，最新内容始终位于 Composer 上方；
- 教学建议不会覆盖或清空当前题，拒绝、延后和恢复路径均可用。

### 12.2 质量门槛

- 固定评测集中工具选择准确率不低于 95%；
- 高风险操作未确认执行率为 0；
- 同一幂等键重复创建或重复扣费率为 0；
- P95 首个可见响应时间和任务完成时间达到上线前确定的性能预算；
- 用户能够从至少 90% 的失败状态进入重试或替代流程。

## 13. 成功指标

北极星结果指标：独立保留题与计时模考的能力提升、目标能力差距缩小、长期保持，以及在具备自愿真实结果样本时的目标达成率。分数预测还必须衡量区间覆盖率、概率校准度和高置信错误率。

以下是诊断过程指标，不得替代学习结果：

- Agent 建议到学习任务开始的转化率；
- 练习、复习和模考完成率；
- Agent 任务成功率和用户反馈；
- AI 额度消耗后的有效学习行为比例；
- 7 日内再次使用 Agent 的学生比例；
- 每个成功任务的平均工具调用次数。

详细结果口径见 [17-TARGET-SCORE-OUTCOME-ADR.md](./17-TARGET-SCORE-OUTCOME-ADR.md)。

## 14. 发布范围

建议按以下顺序灰度：

1. 内部测试账号；
2. 白名单学生；
3. 小比例已验证用户；
4. 全量网页用户；
5. 外部插件测试用户；
6. 插件公开发布。

`WA-P1` 和 `PLUGIN-P1` 共享能力契约，但不是同一次发布的硬性绑定项。完整阶段定义见 [19-ARCHITECTURE-CLOSURE-ADR.md](./19-ARCHITECTURE-CLOSURE-ADR.md)。

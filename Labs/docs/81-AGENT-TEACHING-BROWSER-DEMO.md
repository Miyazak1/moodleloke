# Agent 主动教学浏览器演示

状态：PR13G 已实现，可在本地重复准备并验证“教学—即时验证—保持验证—迁移验证—稳定掌握”真实闭环。

## 目的

这条演示路径验证的不是静态原型，而是正式 Agent 数据模型和正式接口：重复错误证据触发教学建议，教学内容进入可交换、可调整宽度的任务面板，聊天始终保留；学生完成交互微课后，系统提供独立验证入口。

演示不调用大模型 API，也不伪造前端状态。准备脚本只会重置隔离账号 `agent-investor-demo@cscalite.local` 的演示数据，不修改普通学生数据。

## 一键准备

先用 `start-cscalite-dev.bat` 启动本地环境，再在仓库根目录执行：

```powershell
node scripts/agent-teaching-browser-demo-prepare.cjs --apply
```

脚本会先恢复标准演示基线，再创建：

- 4 次“函数水平平移方向判断错误”的真实错因聚合；
- 对应知识点的真实掌握度快照；
- 一条待投递的主动教学干预；
- 一段用于演示的 Agent 对话；
- `.local/agent-teaching-browser-demo.json` 场景入口；
- `.local/agent-demo-credentials.json` 隔离账号凭据。

每次彩排前重新执行同一命令即可回到干净起点。脚本会为隔离账号清理本地演示题的练习曝光、统一测量曝光、学习证据和对应派生状态，但不会放宽正式环境的旧题防复用规则。不要给脚本传 `--keep-baseline`，除非明确需要保留其他隔离账号演示数据。

## 手工彩排

1. 打开脚本输出的 `relativeUrl`，默认前端地址为 `http://localhost:5187`。
2. 使用 `.local/agent-demo-credentials.json` 中的账号登录。
3. 确认聊天中出现“函数水平平移的方向判断已重复出错 4 次”的教学建议。
4. 点击“开始学习”，确认讲解在 Agent 任务面板打开，聊天区仍然存在。
5. 刷新页面，确认讲解面板恢复。
6. 点击“开始讲解”，选择“(3, 0)”，再点击“检查我的判断”。
7. 出现正确反馈后点击“我理解了，完成微课”。
8. 确认讲解面板关闭，聊天中出现“开始验证”。这表明系统没有把内容曝光或完成微课直接计为掌握。
9. 完成 3 道未曝光独立验证题并返回 Agent。
10. 确认聊天明确显示本阶段正确数，并说明“当前通过不等于稳定掌握”；通过即时验证后还会安排到期保持验证。
11. 演示时无需真实等待 24 小时，可在仓库根目录执行下面的本地专用命令，把当前隔离场景的下一项已排期验证推进为到期：

```powershell
node scripts/agent-teaching-stability-demo-advance.cjs --apply
```

12. 刷新 Agent，完成“延迟保持验证”；保持通过后，系统会立即提供“跨题型迁移验证”。
13. 完成迁移验证并返回 Agent，确认聊天只有在即时、保持、迁移三阶段均通过后才显示“三阶段验证已确认稳定掌握”。
14. 打开左栏“学习计划”，确认出现“学习决策变化 / 已确认稳定掌握”，且卡片中的任务是重算后的当前下一任务。
15. 打开“学习历程”，确认即时、保持、迁移后的方案版本按时间展开，并能看到最终“已确认稳定掌握”节点。
16. 打开“错题与薄弱点”，确认显示真实知识点掌握证据和待复习项，而不是跳出 Agent。
17. 打开“学习资料”，选择一份已发布真题，确认资料在 Agent 任务面板打开且聊天仍然存在。
18. 打开“学习设置”，确认学习画像、考试目标和学习时间在可交换任务面板中读取；保存学习时间后确认成功提示，聊天不离开当前学习旅程。
19. 点击左栏底部头像卡的“个人设置”，确认进入账号中心设置分区，而不是再次打开 Agent 学习设置。

PR13K 的首个稳定性门禁在 1440px、1024px 和 393px 三种视口执行 Agent runtime 浏览器测试；学习设置必须在刷新后恢复，桌面和平板还必须恢复面板宽度与聊天/任务顺序。移动端不展示头像卡，也不提供拖动分隔线，学习设置以覆盖式任务面板打开。

PR13K 第二个门禁要求真题任务面板始终展示真实作答进度与整卷复盘，不得为了压缩布局将关键状态隐藏。刷新页面后必须从 URL 恢复当前真题；首次加载失败时应在 Agent 内原地重试，不能把学生送回旧真题页面或要求重新开始对话。

同一门禁覆盖练习、模考作答、模考报告、知识讲解、真题和学习设置的刷新恢复。版本化学习设置发生 `409 VERSION_CONFLICT` 时，面板与聊天必须继续保留，并明确提示刷新后重试，不得假装保存成功或覆盖较新的设置。

PR13K 第三个门禁统一键盘与连接恢复：任务面板可用 `Esc` 关闭，标题栏关闭按钮与 `Esc` 都必须把焦点交还 Composer；分隔线继续支持方向键与 `Home`。SSE 短暂中断时使用 `aria-live` 状态提示“正在恢复”，随后从游标继续连接，不能重复提交学生消息。

如果前端运行在其他端口，将 `relativeUrl` 拼接到实际前端地址即可。

## 自动浏览器彩排

默认端口为 5187：

```powershell
node scripts/agent-teaching-browser-demo-prepare.cjs --apply
cd frontend
npx playwright test --config playwright.agent-teaching-live.config.ts
```

使用自定义前端端口时：

```powershell
$env:AGENT_LIVE_FRONTEND_URL='http://127.0.0.1:4177'
npx playwright test --config playwright.agent-teaching-live.config.ts
```

自动测试覆盖真实登录、主动建议、正式投递、刷新恢复、交互回答、三阶段共九道未曝光题、每阶段正式结算、返回聊天、到期推进、最终稳定掌握结论、学习计划与学习历程中的决策变化、原生薄弱点与可信资料视图，以及 Agent 原生设置读取和学习时间保存。它不会消耗模型额度。测试使用本地专用推进脚本模拟跨日到期，不会改变生产环境的 24 小时保持间隔。

## 边界

- 这条路径验证“教学干预已闭环到即时、保持、迁移三阶段结算和 Agent 下一步”，不把微课完成或任一单阶段通过直接当作稳定掌握。
- 独立验证题仍必须满足未曝光、题源可信和测量版本固定等正式约束；题源不足时应显示短缺，而不是退化为重复旧题。
- 投资人演示和开发验收可以使用该隔离路径；生产环境严禁运行演示准备脚本。
